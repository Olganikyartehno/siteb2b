# ЮнитКонтроль.Запуск — лендинг B2B-сервиса аналитики маркетплейсов

## Название

**ЮнитКонтроль.Запуск** — сервис, который подключается к личным кабинетам Wildberries и Ozon по API и показывает чистую прибыль, маржу, ROI и остатки по каждому артикулу.

## Решаемая задача

Продавцы на маркетплейсах видят выплаты от WB и Ozon, но не понимают главную цифру — сколько реально заработали. Классическая картина:

- «Деньги приходят, но после комиссии, логистики, хранения, налога и возвратов я не понимаю, где прибыль» — один артикул тянет вверх, другой незаметно уходит в минус.
- «Каждое воскресенье свожу 7 таблиц: WB, Ozon, банк, рекламу, 1С, остатки и возвраты» — к понедельнику цифры снова расходятся на 3–7%.
- «Остаток обнуляется внезапно» — карточка выпадает из выдачи за 3–5 дней, либо на складе 2–3 месяца висит 150 000–300 000 ₽ лишнего товара.

Сервис решает эти задачи:
- собирает данные из личных кабинетов WB и Ozon по API за 1 рабочий день;
- через 48 часов после доступов выдаёт отчёт по каждому артикулу: выручка, расходы, чистая прибыль, маржа, ROI, остаток;
- находит артикулы с маржой ниже 10% и уходящие в минус, считает сценарии «+5% к цене», «отключение рекламы», «смена склада»;
- уведомляет в Telegram за 21 день до обнуления остатка и рекомендует объём поставки на основе продаж за 8 недель;
- сверяет итог с выплатами WB и Ozon — расхождение не более 1%, иначе модель дорабатывается бесплатно.

## Пользователь

- Владельцы и операционные менеджеры интернет-магазинов на Wildberries и Ozon.
- Селлеры с 20–500 артикулами, которые сами сводят таблицы и принимают решения поставке/цене вручную.
- B2B-сегмент: компания продаёт под ключ — подключение, первый отчёт, сверка, обучение дашборду за 60 минут.

## Оффер

**4 990 ₽ вместо 8 500 ₽** за запуск и первый месяц (цена фиксируется для оплативших до 23:59 МСК, до 7 магазинов в неделю). Если первый отчёт придёт позже чем через 48 часов после передачи доступов — первый месяц бесплатно.

## Технологии

- Чистый HTML + CSS + ванильный JS, без сборщиков и зависимостей.
- Шрифт Inter (Google Fonts) с системными fallback.
- Цветовая палитра: глубокий тёмно-синий `#1a2332`, изумрудно-зелёный акцент `#10b981`, светло-серый фон `#f8f9fa`, тёмно-серый текст `#374151`.
- Адаптивная вёрстка (desktop / tablet / mobile).
- Анимации: появление секций при скролле (IntersectionObserver), каскадный вход hero, «живые» счётчики KPI, рост столбцов графика; отключаются при `prefers-reduced-motion`.

## Форма заявки и Google Таблицы

Кнопки «Оплатить запуск» открывают модальную форму (имя, контакт, магазины WB/Ozon, комментарий). Заявка отправляется POST-запросом в развёрнутое веб-приложение Google Apps Script и записывается в лист «Заявки» Google Таблицы (столбцы: Дата, Продукт, Имя, Контакт, Магазины, Комментарий).

URL веб-приложения задаётся переменной `GAS_URL` в конце `index.html`. Скрипт для приёма заявок — в `google-apps-script.gs`: функция `doPost` разворачивается как веб-приложение («Развертывание → Новое развертывание → Веб-приложение», доступ: «Все»).

## Запуск локально

Откройте `index.html` в любом браузере — файл не требует сервера. Для разворачивания на хостинге достаточно опубликовать содержимое папки (Netlify Drop, GitHub Pages и т.п.).

## Деплой

Проект опубликован и настроен на автодеплой при пуше в ветку `master`.

| Платформа | URL | Автодеплой |
|-----------|-----|------------|
| Netlify | https://siteb2b.netlify.app | да, через GitHub Actions |
| GitHub Pages | https://olganikyartehno.github.io/siteb2b/ | да, встроенный |

### Как работает автодеплой

1. Пуш в `master` запускает workflow `.github/workflows/netlify-deploy.yml`.
2. Workflow вызывает Netlify Build Hook (секрет репозитория `NETLIFY_BUILD_HOOK`).
3. Netlify собирает и публикует сайт (конфигурация — `netlify.toml`, publish-директория `.`, добавлены security-заголовки).
4. Параллельно GitHub Pages пересобирает сайт из ветки `master`.

### Ручной деплой

- Netlify: `netlify deploy --prod --dir .` из папки проекта.
- Обновить build hook: Netlify → Site configuration → Build & deploy → Build hooks → добавить новый URL в секрет GitHub (`gh secret set NETLIFY_BUILD_HOOK`).
